## Hi, I'm Zac.

I write software by day and build things by night.

Most of my projects run the whole way through: an idea, a model in Fusion 360, then something 3D printed, laser cut, CNC'd or built out of wood, and usually some electronics and code to make it do something. A lot of them end up wired into my house. Electronic parts and unfinished experiments are all over the place.

ZENVENT is where I write those builds up, with the parts, code and what went wrong, in case you want to make one yourself.

Thanks for stopping by.
